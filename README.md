# 📖 About

CodeArena IDE is a modern browser-based Integrated Development Environment inspired by professional editors like **Visual Studio Code**.

Designed with simplicity and scalability in mind, the project delivers a clean and responsive workspace for developers to write, edit, organize, and preview code directly from the browser.

Instead of recreating an IDE, CodeArena focuses on providing a minimal yet powerful coding experience while maintaining a modular architecture that can easily evolve into a full-featured online development platform.

Whether you're learning frontend development, experimenting with UI ideas, or building future developer tools, CodeArena IDE provides a strong foundation with modern web technologies.

# ⚙ Installation

### Clone the Repository

```bash
git clone https://github.com/ApoorvBytes/code-arena-ide.git
```

---

### Navigate to the Project

```bash
cd code-arena-ide
```

---

### Install Dependencies

```bash
npm install
```

---

### Start Development Server

```bash
npm run dev
```

---

### Production Build

```bash
npm run build
```

# 🚀 Usage

Once the development server is running:

1. Open the application in your browser.
2. Create a new project or start editing existing files.
3. Write HTML, CSS, and JavaScript using the Monaco Editor.
4. Organize your project with the built-in workspace.
5. Preview and manage your code efficiently.
6. Export your project whenever required.

# 💡 Design Philosophy

> **A development environment should feel invisible.**

CodeArena IDE is designed around the idea that developers should spend their time writing code—not fighting the interface.

Every component has been built with three principles in mind:

- **Minimalism**
- **Performance**
- **Scalability**

The modular architecture allows future expansion without requiring major structural changes.
